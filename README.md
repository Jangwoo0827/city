# 미니 시티 (Mini City)

브라우저에서 돌아가는 도시 건설 시뮬레이션 프로토타입입니다. 시티즈: 스카이라인처럼 도로를 깔고, 구역을 지정하고, 발전소를 연결해 도시를 키웁니다.
3D 아이소메트릭 시점이며 **외부 에셋(모델/텍스처/이미지) 없이 코드로 만든 도형만** 사용합니다.

- Vite + TypeScript + Three.js (React 등 다른 프레임워크 없음, CDN 의존 없음)
- UI는 HTML/CSS 오버레이, 한국어

## 실행 방법

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 타입 체크 + 프로덕션 빌드 (dist/)
npm run preview    # 빌드 결과 미리보기
npm run typecheck  # TypeScript 타입 체크만
```

Node.js 18 이상을 권장합니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 우클릭(또는 휠 클릭) 드래그 | 화면 이동 (pan) |
| 마우스 휠 | 줌 (커서 위치 기준, 범위 제한) |
| `Q` / `E` | 카메라 90° 회전 (부드럽게 보간) |
| `W A S D` / 방향키 | 화면 이동 |
| 좌클릭 / 드래그 | 선택한 도구 사용 |
| `1` ~ `5` | 도구 선택 (도로 / 구역 / 발전소 / 철거 / 정보) |
| `R` `C` `I` | (구역 도구 사용 중) 주거 / 상업 / 공업 선택 |
| `Space` | 일시정지 / 재개 |
| `Esc` | 정보 도구로 돌아가기, 진행 중인 드래그 취소 |
| 터치: 한 손가락 드래그 | 이동 (탭하면 해당 타일에 도구 사용) |
| 터치: 두 손가락 핀치 | 줌 |
| 터치: 하단 `✋ 드래그: 이동` 버튼 | `✏️ 드래그: 건설`로 전환하면 한 손가락 드래그로 도로·구역을 그릴 수 있음 |

## 건설 도구

1. **도로** – 드래그하면 시작점에서 주축 방향의 직선으로 설치됩니다. 인접한 도로는 자동으로 연결되며 직선/코너/T자/십자 모양이 자동으로 바뀝니다.
2. **구역** – 주거(초록) / 상업(파랑) / 공업(노랑) 영역을 드래그로 지정합니다. **도로에 인접한 타일에만** 지정할 수 있습니다.
3. **발전소** – 2×2 건물. 도로에 붙여 설치하면 연결된 도로망 전체에 전력을 공급합니다.
4. **철거** – 드래그로 영역 안의 도로/구역/건물을 제거합니다. 환급은 없습니다.
5. **정보** – 타일이나 건물을 클릭하면 우측 패널에 상세 정보(레벨, 인구/일자리, 세금, 전력, 성장률 등)가 표시됩니다.

호버/드래그 중에는 타일이 초록(설치 가능) / 빨강(불가)으로 표시되고, 커서 옆에 비용이 나타납니다.

## 시뮬레이션 규칙

시간: **1초 = 1틱 = 게임 내 1일** (속도 ×1/×2/×3, 일시정지 가능).

- **성장 조건** – 구역 타일이 ① 도로에 인접하고 ② 전력이 연결되어 있어야 건물이 생기고 자랍니다.
- **전력** – 발전소에 붙은 도로에서 시작해 도로망을 따라 BFS로 전파됩니다. 전력이 닿은 도로(또는 발전소)에 인접한 구역이 전력을 공급받습니다.
- **레벨 1~3** – 수요가 높을수록 빠르게 성장합니다. 레벨마다 높이·색이 달라집니다 (주거: 낮고 지붕 있음, 상업: 중간~높은 유리 건물, 공업: 굴뚝 달린 낮은 박스).
- **RCI 수요** (좌측 하단 막대, 위로 차오를수록 해당 구역이 필요)
  - 주거: 일자리가 노동력(인구의 일부)보다 많을수록 ↑ (행복도도 영향)
  - 상업: 주민(고객)이 상업 일자리보다 많을수록 ↑, 인구가 없으면 0
  - 공업: 노동력이 일자리보다 많을수록 ↑ (일자리 공급원)
- **행복도 (0~100)** – 전력 유무, 공업 오염(주거지 주변 3타일), 일자리 균형(실업)으로 결정됩니다.
- **경제** – 틱마다 건물 레벨에 비례한 세금(행복도에 따라 0.5~1.5배, 전력이 있는 건물만 납세)을 받고, 도로 유지비와 발전소 유지비를 지불합니다.
- **시작 자금** ₩20,000. 자금이 **−₩5,000 미만**이 되면 파산 → 게임 오버 화면.
- **마일스톤** – 인구 100 / 500 / 2,000명 도달 시 알림.

## 시각 연출

- 같은 모양의 건물/도로는 `InstancedMesh`로 그려 64×64 맵을 가득 채워도 약 60fps를 유지합니다.
- 도로 위를 오가는 자동차 (도로 3칸당 1대, 최대 60대)
- 건물이 새로 지어지거나 레벨업할 때 아래에서 솟아오르는 애니메이션
- 2분 주기의 낮/밤 – 태양·달 이동, 하늘/안개 색 변화, 밤에는 건물 창에 불이 켜짐
- 그림자 있는 방향광 + 환경광, 하늘색 배경, 가벼운 안개

## 저장

- `localStorage`에 **30초마다 자동 저장**되고, 탭을 닫거나 새로고침할 때도 저장됩니다. 접속하면 저장된 도시가 자동으로 복원됩니다.
- 우측 상단 `☰` 메뉴에서 수동 저장 / 불러오기 / 새 게임 / 도움말을 사용할 수 있습니다.

## 코드 구조

```
src/
  main.ts          진입점: 상태/뷰/UI 연결, 메인 루프(시뮬레이션 틱 + 렌더), 자동 저장
  game/
    state.ts       GameState (격자, 자금, 통계, 이벤트, 변경 플래그)
    simulation.ts  1틱 진행: 집계 → 수요 → 성장 → 행복도 → 경제 → 마일스톤/파산
    economy.ts     세금·유지비 계산
    power.ts       도로망 BFS 전력 전파
    demand.ts      RCI 수요 계산
    actions.ts     도구별 미리보기/적용 (도로·구역·발전소·철거)
  world/
    grid.ts        타일 종류와 격자 데이터(TypedArray)
    roads.ts       도로 연결 마스크, 직선 경로
    zones.ts       구역 타입, 사각형 영역
    buildings.ts   건물 수치(인구/일자리/세금), 발전소 풋프린트
  render/
    scene.ts       three.js 씬, 조명, 바닥, 선택 마커
    camera.ts      아이소메트릭 직교 카메라 (이동/줌/회전)
    instancing.ts  도로·구역·건물 InstancedMesh 동기화, 솟아오름 애니메이션
    models.ts      건물 모델(절차적 도형)
    geometry.ts    박스/원기둥/지붕/창 지오메트리 헬퍼
    overlay.ts     호버·드래그 미리보기 하이라이트
    cars.ts        자동차
    daynight.ts    낮/밤 주기
  ui/
    hud.ts         상단 바, RCI 바, 토스트, 메뉴, 게임 오버
    toolbar.ts     하단 도구 모음
    panels.ts      정보 패널, 툴팁
    input.ts       마우스/터치/키보드 입력
    styles.css     어두운 반투명 패널 스타일
  utils/
    constants.ts   모든 밸런스·튜닝 상수
    save.ts        localStorage 저장/불러오기
    math.ts        수학 유틸
```
