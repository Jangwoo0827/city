# 미니 시티 (Mini City)

브라우저에서 돌아가는 도시 건설 시뮬레이션 프로토타입입니다. 시티즈: 스카이라인처럼 도로를 깔고, 구역을 지정하고, 발전소를 연결해 도시를 키웁니다.
3D 아이소메트릭 시점이며 **외부 에셋(모델/텍스처/이미지) 없이 코드로 만든 도형만** 사용합니다.

- Vite + TypeScript + Three.js (React 등 다른 프레임워크 없음, CDN 의존 없음)
- UI는 HTML/CSS 오버레이, 한국어

## 실행 방법

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 타입 체크 + 프로덕션 빌드 (dist/)
npm run preview    # 빌드 결과 미리보기
npm run typecheck  # TypeScript 타입 체크만
npm test           # 단위 테스트 (Vitest)
npm run sim        # 헤드리스 밸런스 시뮬레이터 (npm run sim -- 3000 250)
```

Node.js 18 이상을 권장합니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 우클릭(또는 휠 클릭) 드래그 | 화면 이동 (pan) |
| 마우스 휠 | 줌 (커서 위치 기준, 범위 제한) |
| `Q` / `E` | 카메라 90° 회전 (부드럽게 보간) |
| `W A S D` / 방향키 | 화면 이동 |
| 좌클릭 / 드래그 | 선택한 도구 사용 |
| `1` ~ `5` | 도구 선택 (도로 / 구역 / 발전소 / 철거 / 정보) |
| `R` `C` `I` | (구역 도구 사용 중) 주거 / 상업 / 공업 선택 |
| `Space` | 일시정지 / 재개 |
| `Esc` | 정보 도구로 돌아가기, 진행 중인 드래그 취소 |
| 터치: 한 손가락 드래그 | 이동 (탭하면 해당 타일에 도구 사용) |
| 터치: 두 손가락 핀치 | 줌 |
| 터치: 하단 `✋ 드래그: 이동` 버튼 | `✏️ 드래그: 건설`로 전환하면 한 손가락 드래그로 도로·구역을 그릴 수 있음 |

## 건설 도구

1. **도로** – 드래그하면 시작점에서 주축 방향의 직선으로 설치됩니다. 인접한 도로는 자동으로 연결됩니다(직선/코너/T자/십자). 하단 서브바에서 **소형 / 중형 / 대형** 도로를 고르고, 같은 자리에 더 큰 도로를 덮으면 차액만 내고 업그레이드됩니다. 중형·대형은 개발 트리에서 해금해야 합니다.
2. **구역** – 주거(초록) / 상업(파랑) / 공업(노랑) 영역을 드래그로 지정합니다. **도로에서 4칸 이내**(대형 도로는 6칸)인 타일에만 지정할 수 있습니다.
3. **시설** – 전력(풍력 터빈·석탄 발전소), 상수도(취수장·급수탑·지하수 우물), 하수(배출구·폐수 처리장). 취수장·배출구는 **물 타일에 붙여서** 설치합니다.
4. **철거** – 드래그로 영역 안의 도로/구역/건물을 제거합니다. 환급은 없습니다.
5. **정보** – 타일이나 건물을 클릭하면 우측 패널에 상세 정보(레벨, 인구/일자리, 세금, 전력·수도·하수 상태, 성장률 등)가 표시됩니다.

호버/드래그 중에는 타일이 초록(설치 가능) / 빨강(불가)으로 표시되고, 커서 옆에 비용이 나타납니다.

## 맵과 구획

- 맵은 64×64이며 16×16칸 **구획** 16개로 나뉩니다. 처음에는 **중앙 32×32(구획 4개)** 만 쓸 수 있습니다.
- 어두운 구획을 클릭하면 **돈을 내고 해금**할 수 있습니다. 이미 연 구획과 맞닿은 구획만 가능하고(노란 테두리), 많이 살수록 비싸집니다.
- 물(호수·강·연못) 위에는 건설할 수 없습니다.

## 진행: 마일스톤 · 개발 트리 · 재정

- **XP**는 도로·시설 건설, 건물 생성·성장, 인구 증가로 쌓이고 **20단계 마일스톤**을 올립니다. 단계마다 현금, 개발 포인트, 대출 한도를 받습니다.
- **개발 트리**(상단 🏆 또는 `M` 키): 개발 포인트로 석탄 발전소, 중형·대형 도로, 급수탑, 지하수 우물, 폐수 처리장 등을 해금합니다. 풍력·취수장·배출구·소형 도로는 처음부터 사용할 수 있습니다.
- **재정**: 일 수입/지출 내역, 대출(₩5,000 단위, 일 0.05% 이자), 다음 구획 가격.

## 시뮬레이션 규칙

시간: **1초 = 1틱 = 게임 내 1일** (속도 ×1/×2/×3, 일시정지 가능). 다른 탭을 보는 동안에도 진행됩니다.

- **성장 조건** – 구역 타일이 ① 도로에 접근할 수 있고 ② **전력 ③ 상수도 ④ 하수 처리**가 모두 공급되어야 건물이 생기고 자랍니다.
- **네트워크** – 도로가 배선·배관입니다. 시설에 붙은 도로망을 따라, 같은 도로망의 용량이 허락하는 만큼 **시설에서 가까운 구역부터** 공급되고 모자라면 먼 곳부터 끊깁니다. 좌측 패널의 ⚡💧🚰를 누르면 공급(초록)/끊김(빨강) 오버레이를 볼 수 있습니다.
- **상수도** – 취수장은 물 타일 옆에서만 설치되며 수질이 오염되면 용량이 줄어듭니다. 지하수 우물은 많이 쓰면 고갈되고 서서히 회복됩니다.
- **하수** – 배출구로 흘려보낸 하수는 수질을 오염시킵니다(양이 적으면 자연 정화). 폐수 처리장은 오염 없이 처리합니다. 오염은 행복도와 취수 용량을 떨어뜨립니다.
- **레벨 1~3** – 수요가 높을수록 빠르게 성장합니다. 레벨마다 높이·색이 달라집니다.
- **RCI 수요** (좌측 하단 막대) – 주거: 일자리가 노동력보다 많을수록 ↑ / 상업: 주민이 상업 일자리보다 많을수록 ↑ / 공업: 노동력이 일자리보다 많을수록 ↑.
- **행복도 (0~100)** – 전력·수도·하수 공급, 수질 오염, 공업 오염, 일자리 균형(실업)으로 결정됩니다.
- **경제** – 틱마다 세금(전력·수도·하수가 모두 공급되는 건물만 납세, 행복도에 따라 0.5~1.5배)을 받고, 도로·시설 유지비와 대출 이자를 냅니다.
- 시작 자금 ₩20,000. 자금이 **−₩5,000 미만**이면 파산(게임 오버). 인구 100 / 500 / 2,000명 도달 시 알림.

## 시각 연출

- 같은 모양의 건물/도로는 `InstancedMesh`로 그려 64×64 맵을 가득 채워도 약 60fps를 유지합니다.
- 도로 위를 오가는 자동차 (도로 3칸당 1대, 최대 60대)
- 건물이 새로 지어지거나 레벨업할 때 아래에서 솟아오르는 애니메이션
- 2분 주기의 낮/밤 – 태양·달 이동, 하늘/안개 색 변화, 밤에는 건물 창에 불이 켜짐
- 그림자 있는 방향광 + 환경광, 하늘색 배경, 가벼운 안개

## 저장

- `localStorage`에 **30초마다 자동 저장**되고, 탭을 닫거나 새로고침할 때도 저장됩니다. 접속하면 저장된 도시가 자동으로 복원됩니다.
- 우측 상단 `☰` 메뉴에서 수동 저장 / 불러오기 / 새 게임 / 도움말을 사용할 수 있습니다.
