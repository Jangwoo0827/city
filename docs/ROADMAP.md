# 미니 시티 확장 계획 v2

참고 자료: 나무위키 「시티즈: 스카이라인 II」 본문·건설 도구·고유건물·랜드마크·마일스톤·지도 문서, **「시티즈: 스카이라인(CS1)」 건설 도구·맵 문서(v2.1에서 도로·맵·발전소 반영)**, 그리고 `w citys.md`(도전 과제 목록 + CS2 핵심 시스템 정리 + 미니 게임 이식 순서).

> **자료의 한계** (확인 필요 표시는 본문에 `※`)
> - 건설 도구·랜드마크·마일스톤 문서에는 수치가 있지만, **고유건물 문서는 주거 건물 이름과 효과 문장만**, **지도 문서는 맵 크기·타일 수·구매 비용이 없고** 맵별 기후·허가 구역 비율·자원 등급만 있다.
> - 마일스톤 표의 19·20단계 필요 XP가 같은 값(592,700)으로 적혀 있다 ※ 오기로 보고 20단계는 추정값을 쓴다.
> - CS2 금액은 이 게임과 소득 규모가 달라 **직접 환산하면 파산/무한 부자가 된다**. 그래서 CS2 수치는 *상대 비율*(예: 병원:진료소 = 수용 5배, 건설비 약 30배)만 참고하고, 절대 수치는 이 게임 경제에 맞춰 새로 잡는다.

## 확정된 결정과 구현 현황 (최신)

**확정된 결정**
- **맵**: 64×64 맵을 16×16칸 구획 4×4로 나눈다. **시작은 중앙 2×2구획(32×32칸)**, 나머지 12구획은 **돈으로만** 구매한다(확장 허가 없음). 구획은 이미 연 구획과 맞닿아 있어야 하고, 가격은 `2,000 × (1 + 구매한 구획 수 × 0.6)`. *(아래 3.1·3.12절의 "확장 허가/기본 9구획/대형 맵 모드" 서술은 이 결정으로 대체됨)*
- **진행 순서**: P0 → P1 → P2 순서로 진행.
- 맵 프리셋·자원 타일은 P10에서. 현재는 기본 맵 1종(**128×128**, 호수·강·연못 물 타일 포함).
- 서비스 커버리지는 1차로 **유클리드 반경** 방식(도로 경로 기준은 추후 옵션).

**계획 대비 달라진 점 / 알려진 단순화**

- 수치(용량·유지비·XP 보상)는 `npm run sim` 으로 보정 중이며 초안이다.

## 1. 현재 상태와 원칙

**있는 것**: 도로(자동 연결), 구역 R/C/I × 레벨 1~3, 발전소 1종(전력 BFS), RCI 수요, 행복도(전력·오염·실업), 세금/유지비, 파산, 저장/불러오기, 낮/밤, 자동차, 정보 패널.

**원칙**
1. **데이터 주도**: 건물·서비스·정책·도전 과제는 `world/catalog.ts` 등 테이블 한 곳에 정의. 새 콘텐츠 = 테이블 한 줄 + 모델.
2. **레이어 맵**: 땅값·범죄·건강·오염·소음·커버리지는 `Float32Array` 레이어, N틱마다 분산 갱신, 오버레이로 시각화.
3. **절차적 도형만**: 모든 모델은 코드 도형(현재 방식 유지). 건물 종류가 늘어도 `InstancedMesh` + 모델 레지스트리.
4. **저장 버전 관리**: 세이브 `v`를 올리고 마이그레이션. (기존 도시 보존)
5. **한 단계 = 체감되는 새 루프 하나**. 단계마다 푸시·배포.
6. **밸런스 도구 먼저**: 시스템이 늘어나기 전에 헤드리스 시뮬레이터(`npm run sim`)를 만든다.

## 3. 시스템별 설계

### 3.1 진행 시스템: 마일스톤 20단계 (XP)

CS2: 도로 건설·건물 건설·인구 증가·건물 레벨업으로 XP를 얻고, 단계마다 **돈 / 개발 포인트 / 확장 허가 / 대출 한도**를 받는다. 1~5단계에서 서비스 그룹이 풀리고, 5단계 이후는 보상만 증가.

**XP 획득 (초안)**: 도로 1칸 +2, 건물 생성 +10, 건물 레벨업 +20×레벨, 시민 10명당 +1/일, 서비스/인프라 건설 +30, 랜드마크 +500.

| 단계 | 이름(원작 참고) | 필요 XP (원작÷4) | 보상 돈 | 개발 포인트 | 확장 허가 | 대출 한도 | 해금 그룹 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 0 | (시작) | 0 | — | 1 | 시작 구획 1 | 5,000 | 도로, R/C/I 구역, 풍력·석탄, 급수/하수 기본 |
| 1 | 아주 작은 부락 | 190 | 625 | +1 | 0 | 10,000 | **의료·장례, 폐기물** |
| 2 | 작은 부락 | 625 | 1,250 | +2 | **+1** | 15,000 | **교육** |
| 3 | 큰 부락 | 1,200 | 1,875 | +3 | 0 | 20,000 | **소방, 경찰** |
| 4 | 아주 큰 부락 | 2,100 | 2,500 | +4 | **+1** | 25,000 | **지구 도구, 정책, 대중교통, 공원·오락** |

- **개발 포인트(Dev Point)**: 해금된 그룹 안의 *개별 건물/도구*(개발 트리 노드)를 푸는 데 소비. 예) 교육 그룹: 초등학교(1pt) → 고등학교(2pt) → 대학교(4pt).
- **확장 허가(Permit)**: 맵 구획(**16×16칸**, 맵은 4×4=16구획) 하나를 구매할 때 허가 1개 + 금전 비용(구획 수에 비례, 예 1,000×N)을 소모. 시작은 1구획, 허가는 총 8개(= **기본 최대 9구획**, CS1의 "25구획 중 9구획" 비율). **대형 맵 모드**(CS1의 25/81타일 모드 대응)는 16구획 전부 무료 개방 — 성능·난이도 옵션.
- 마일스톤 달성 연출: 상단 토스트 + 보상 패널 + 해금 목록.

### 3.2 구역과 건물 (RCIO)

| 구역 | 레벨 | 비고 |
| --- | --- | --- |
| 주거 저밀 | 1~3 | 현재와 동일 |

| 공업 일반 | 1~3 | 상업에 *상품* 공급, 오염 |
| **특수 산업** | 1~3 | **농업(곡물·채소), 광업(광석), 임업(원목), 석유** — 해당 *자원 타일* 위에만 지정 가능 |
| **사무(O)** | 1~3 | **2레벨부터 고학력 필요**, *상업 구역이 없으면 건물이 지어지지 않음*(원작 규칙) |

- **구역 깊이**: CS1은 **도로 좌우 4칸**, CS2는 6칸까지 구역 지정 가능. 현재는 도로에 *바로 인접한 1칸*만 → **도로로부터 거리 4칸(기본), 대로 6칸**으로 확장. 건물은 도로 접근(가장 가까운 도로 칸까지 BFS)이 필요. 고속도로는 구역 지정·주차 불가.
- **고밀 구역(CS1)**: 면적당 약 5배 수용(밀도가 높은 것이지 인구 증가 속도가 빠른 것이 아님), 상업 고밀은 교육 수준 요구·소음이 큼. 사무는 오염이 없지만 수입 물동량이 많아 교통 부하를 만듦.
- **폐허**: 전력·수도·도로 접근·수요·서비스 중 하나가 `ABANDON_TICKS` 동안 끊기면 폐허(어두운 모델, 세금 0, 행복 −). 철거하거나 복구 시 회복.
- **레벨 규칙**: 레벨업 = 수요 + 토지가치 + 서비스 점수(고밀·사무일수록 엄격). 지금의 "수요만" 규칙에서 확장.

### 3.3 기반시설 4종 (모두 "도로 아래 자동 매설" = BFS, 전력과 같은 방식)

원작: 전력선·상하수도는 도로 아래 자동으로 깔리고, 고출력은 송전선/변전소가 필요. 이 게임: **도로 = 케이블·배관**이라는 현재 규칙을 그대로 확장.

**전력** (현재 BFS 유지 + 용량 도입)

- **부족 처리**: 컴포넌트 공급 < 수요면 *말단(발전소에서 BFS 거리 먼 곳)부터* 정전. 정전 건물은 성장 정지·행복 −·폐허 위험.

### 3.4 시민: 교육·건강·연령

- **교육 4단계 (0 무학 ~ 3 대졸)**. 학교 = *커버리지 + 수용량*: 초등 → 고등 → 대학교(+연구 시설). 시민의 학력 분포는 학교 커버·정원에 따라 시간이 지나며 상승.
- **일자리 ↔ 학력 매칭**: 공업/저밀 상업 = 0~1, 고밀 상업 = 1~2, 사무 = 2~3. 학력이 안 맞으면 *유효 일자리*가 줄고 실업이 생김 → RCI 수요에 반영.
- **건강/연령**: 인구를 어린이·성인·노인 비율로 단순화. 병원 커버가 낮으면 사망률·질병 ↑, **묘지/화장터** 용량 초과 시 행복 −. (시민 개별 AI는 범위 제외 유지)
- **시민 연출(후순위)**: 점이 출퇴근하는 연출 전용 에이전트(실제 교통 계산과 분리). 도전 과제 "스토커"는 점 하나를 선택해 *일생을 요약 텍스트로 보여주는* 기능으로 대체.

### 3.6 땅값·매력도·관광

- **땅값 레이어**: 도로 인접·서비스·공원·상업 근접 ↑, 오염·소음·범죄·쓰레기 ↓ → 건물 레벨 상한과 세금에 반영.
- **매력도(Attractiveness)**: 도시 전체 지표(공원·랜드마크·청결·행복·교통). 매력도가 높으면 **관광객** 유입 → 호텔·상업 수입, 외부 연결(고속도로/공항)이 있어야 방문.
- 원작 랜드마크 지표: **실내오락(Indoor) / 실외오락(Outdoor) / 매력(Attractiveness)** 3개 수치 — 그대로 차용.

### 3.7 자원 공급망 (간이)

원작은 원자재 9종 + 가공품 12종 + 서비스 상품 4종. 이 게임은 **`w citys.md` 권장대로 1~2종씩만**:

```
원자재(자원 타일)        가공(공업)            판매/소비
곡물  (비옥지 농업) ──→  식품 공장  ──→  상업(식료)
광석  (광업)        ──→  금속 공장  ──→  상업(생활)·건설 자재(후기)
(후기) 원목 → 가구, 석유 → 플라스틱
        ↓ 부족분 수입 / 남는 양 수출 (외부 연결 필수, 트럭 이동 연출)
```
- 상업 건물은 *상품 재고*가 필요 → 없으면 레벨업 정지. 상품은 가공품(국내) 또는 수입.
- 특수 산업 구역은 맵의 **자원 등급**(비옥지·원목·광석·석유, 원작 지도 표의 4종)에 따라 생산량 결정.
- 수출입 단가표, 무역 수지는 예산 패널에 표시.

### 3.8 경제

- **구역별 세율**(R/C/I/O 0~20%) 슬라이더: 세율↑ → 수입↑, 수요·행복↓.
- **서비스 예산**(그룹별 50~150%): 유지비 ∝ 예산, 효과/수용량 ∝ 예산.
- **대출**: 마일스톤마다 한도 증가(3.1 표). 소액/중액/대액 3종 이자. 도전 과제 "빚더미"는 한도 대비 비율로 변환.
- **예산 패널**: 수입(구역별 세금·유틸리티 요금·관광·수출) / 지출(서비스·도로·인프라·이자·수입품) 표 + 최근 60틱 순이익 그래프.
- **파산**: 현재(−5,000) 유지하되 *대출 한도 초과 시*로 개선.

### 3.9 도로·건설 도구·교통 (CS1 체계 반영)

CS1 건설 도구 문서의 도로 체계를 기본으로, CS2의 도구 모드·교량·교차로를 단계적으로 가져온다. **도로는 구역 지정·전력·수도·하수·쓰레기 경로를 겸하므로 도로 종류가 곧 도시 구조를 결정한다.**

**공통 규칙 (CS1)**
- 도로 좌우 **4칸**에 구역 지정·건물 건설 (고속도로 제외).

**도구 모드** (CS1/CS2): 직선(현재) → **곡선**(베지어를 격자에 래스터화) → **연속 그리기** → **그리드(블록 채우기)** → **업그레이드/교체**(소로→대로, 일방통행 방향 변경) → **평행 도로**, **스냅**. 고도(Page Up/Down)는 교량 구현 시.
- ※ 이번에 읽은 CS1 건설 도구 문서는 도로 건설 방식(직선·곡선·원형·그리드)과 철거 방법 부분이 잘려 있어 *수치 외 조작 세부*는 CS2 자료와 일반 지식으로 보완했다.
- **도로 부속물**: 신호등·일시정지·회전 금지·횡단보도·가로등·잔디·나무·방음벽. 간소화: 가로등(밤 불빛), 가로수(땅값↑), 방음벽(소음↓), 신호등(교통 단계에서 효과).
- **신호 체계**: CS1은 유럽식(좌회전 비보호, 우회전 신호). 이 게임은 교통 단계(P14)에서 "신호 있음/없음"으로만 단순화.

**교통** — `w citys.md` 권고대로 **마지막**. (1) 연출 전용 시민 점 → (2) 링크별 교통량/혼잡 오버레이(도로 속도·차선이 용량) → (3) 대중교통(버스·택시 → 철도/지하철 → 공항). 도전 과제 "교통 노선 20/50개"는 (3)에서 적용.

### 3.12 맵과 환경 (CS1 맵 + CS2 지도 반영)

**CS1 맵 구조에서 가져올 것**
- 맵은 **구획(타일) 격자**로 되어 있고 **기본 설정에서는 일부(25구획 중 9구획)만 구매** 가능. 25/81구획은 모드(대형 맵). 구매 비용·해금 조건 수치는 문서에 없다 → 이 게임은 *허가 + 금전*(3.1)로 설계.
- **테마(기후)마다 고유 효과**가 있고 **가용 면적(평지 비율)** 이 넓을수록 다음 레벨에 필요한 인구가 늘어난다.
- 맵마다 **외부 연결(고속도로·항로·해로·철도)** 과 **자원(수원·농지·광물·석유·산림)** 이 다르다. (문서에는 연결·자원의 유무 표기만 있고 양은 없음 ※)

| **P2** | **상수도·하수** (전력과 동일 BFS, 수원 타일, 용량) + 구역 깊이 N칸 | 취수장 없으면 건물 성장 정지, 도로만 깔면 자동 연결 | 중 |
| **P3** | **서비스 커버리지**: 진료소/병원/경찰/소방/공원 + 반경 오버레이 + 수용량 | 서비스 설치 시 지표 변화, 커버 밖 건물 불이익 | 큼 |
| **P4** | **교육 0~3단계 + 사무(O) 구역 + 학력-일자리 매칭** | 학교 없이는 사무 레벨 상한, 실업 구조 변화 | 중 |
| **P5** | **땅값 맵 + 구역 세분화(저/중/고밀) + 폐허** | 공원/서비스 주변이 비싸지고 고밀이 생김 | 중 |
| **P6** | **예산·세율·대출·수출입 틀** (경제 패널) | 구역별 세율 조정 → 수입·수요 변화 | 중 |
| **P7** | **전력 용량·발전소 종류·변전소·배터리·재생에너지** | 정전 말단부터 발생, "배출 제로" 가능 | 중 |
| **P8** | **쓰레기·묘지·건강/연령** | 수거 트럭 연출, 미수거 누적 불이익 | 중 |
| **P9** | **자원 체인(곡물·광석 → 식품·금속 → 상업)** + 특수 산업 구역 + 자원 타일 | 상품 재고로 상업 성장 제어, 수출입 | 큼 |
| **P10** | **맵 프리셋 8종**(4테마 효과·물·자원·외부 연결) + 교량 + 기후/계절 + 이벤트(우박·토네이도·산불·범람) | 맵 선택 화면, 테마별 효과 | 큼 |
| **P11** | **관광·매력도·랜드마크·고유건물** | 매력도→관광객→수입 | 중 |
| **P12** | **지구·정책·도전 과제·사진 모드·조경** | 도전 과제 패널, 정책 효과 | 중 |
| **P13** | **도로 종류 CS1 체계 전체**(소형/중형/대형/고속, 잔디·가로수·산업·비포장·비대칭) + 로터리·톨게이트 + 도구 모드(곡선/그리드/업그레이드) | 도로 선택 팝업, 구역 깊이 4(대로 6) | 중 |
| **P14** | **시민 점 연출 → 교통량 오버레이 → 대중교통** | 마지막 단계(교통) | 큼 |

> 도로 확장(P13)은 구역 깊이·전송 한도와 얽혀 있어 **P2에서 "구역 깊이 4 + 소형/중형/대형 3종"까지 앞당기고**, P7에서 대형 도로를 고전압 한도와 연결한 뒤, 나머지(변형·고속도로·교차로·도구 모드)는 P13에서.

## 6. 밸런스 방침

- **목표 곡선(플레이 시간)**: 0~5분 마일스톤 1~2, 순수입 ≥ 0 / 5~15분 마일스톤 4~5(서비스 전부 해금) / 15~40분 인구 5,000·고밀·사무 / 1시간+ 마일스톤 10~15 / 20단계는 *수 시간* 목표.
- **파산 요인 다양화**: 도로 과잉뿐 아니라 서비스 유지비·대출 이자·적자 인프라에서도 위험.
- **헤드리스 시뮬레이터**: 정해진 건설 시나리오(스크립트)를 시드 고정으로 N틱 실행 → 인구·자금·XP 곡선 CSV. 상수 변경 PR마다 비교.
- **난이도 프리셋**: 쉬움(시작금 ×2, 유지비 ×0.7, 재해 off) / 보통 / 어려움(대출 의존, 재해 ↑).
- 모든 수치는 `constants.ts`/`data/*.ts`에만.

## 7. 리스크

- **범위 폭발**: 상하수도·자원·교육·교통을 전부 하면 CS2급. → 위 단계마다 *출시 가능한 상태*를 유지하고, P9(자원)·P14(교통)는 선택 사항으로 둔다.
- **UI 복잡도**: 툴바 5개 → 30개+. 카테고리 팝업·잠금 표시·툴팁 필수.
- **성능**: 서비스/오버레이/레이어 갱신 분산, `InstancedMesh` 종류 증가 → 모델 병합·LOD(줌아웃 시 창문 메시 제외).
- **BFS 3종 + 용량 계산** 비용: 변경 시에만 재계산(dirty 플래그)하고 컴포넌트 단위 캐시.
- **자료 부족**: 고유건물·지도·랜드마크 배치 규칙은 원작 문서에 없음 → 원안 설계를 플레이테스트로 보정.

## 8. 결정이 필요한 항목

1. **P0~P2부터 시작**해도 될까요? (기반 정비 → 마일스톤 → 상하수도) 아니면 눈에 띄는 서비스 건물(P3)을 먼저?
2. **맵 구획 구매**(16×16칸, 시작 1구획, **기본 최대 9구획** + 대형 맵 모드)를 도입할지, 64×64 전부 열어 둘지.
3. **물 타일/자원 타일**을 도입(지형 높이는 제외)해도 되는지. (상수도·농업·광업에 필요)
4. **자원 공급망(P9)** 과 **교통(P14)** 은 선택 사항으로 두어도 되는지.
5. 도전 과제를 **계정 단위(도시 간 누적)** 로 저장해도 되는지.
6. 서비스 반경을 처음부터 **도로 경로 기준**으로 할지(정확하지만 무겁다), 반경으로 시작하고 나중에 바꿀지.
